# BRIGHT-TV-ANALYSIS

Overview
This case study analysed Bright TV subscriber viewing behaviour and content consumption patterns to identify opportunities for subscriber growth and increased engagement.

Process
Cleaned and prepared user and viewing data.
Analysed viewing trends and consumption patterns.
Identified most and least watched content.
Investigated factors influencing consumption, including genre, age group, subscription package, and viewing time.
Developed data-driven growth recommendations.

Key Insights
Viewing behaviour varies across customer segments.
Certain content genres drive higher engagement.
Peak viewing periods present opportunities for targeted promotions.
Personalised content recommendations can improve retention and subscriber growth.

Tools Used
Databricks
SQL
Power BI
Excel
GitHub

Outcome
Provided actionable recommendations to help Bright TV increase engagement, improve retention, and support subscriber growth.
